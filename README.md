# Networking Tools

A collection of networking utilities and hands-on projects exploring network discovery, port scanning, and TCP/UDP communication.

This repository brings together small tools and experiments for learning how networks work, exploring common networking concepts, and working directly with network protocols. Each project lives in its own directory and focuses on a specific area of networking.

## Projects

| Project | Description |
| --- | --- |
| [network-scanner](./network-scanner/) | Explores network discovery and identifying hosts on a network. |
| [port-scanner](./port-scanner/) | Explores port scanning and checking the availability of network services. |
| [tcp-udp-server](./tcp-udp-server/) | Experiments with TCP and UDP server communication and transport-layer networking. |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/QuantumZenoSix/networking-tools.git
cd networking-tools
```

Choose a project directory and review its files for specific dependencies, setup instructions, and usage examples. Each project may have its own requirements and execution steps.

## What I'm Exploring

- **Network discovery:** Understanding how hosts and devices can be identified on a network.
- **Port scanning:** Learning how network services expose ports and accept connections.
- **Network protocols:** Working with TCP and UDP to understand connection-oriented and connectionless communication.
- **Practical networking:** Building small tools to explore concepts through hands-on experimentation.

## Responsible Use

Use these tools only on systems and networks you own or have explicit permission to test.
